My Portfolio Website

A responsive personal portfolio website showcasing my skills, projects, education, achievements, and contact information. Built with modern web technologies to create a professional online presence.

🌟 Features

- **Responsive Design** - Optimized for all devices (desktop, tablet, mobile)
- **About Section** - Personal introduction and background
- **Education Section** - Academic qualifications and achievements
- **Skills Section** - Technical skills, tools, and concepts
- **Projects Showcase** - Display of personal and professional projects
- **Certificates Section** - Professional certifications and internships
- **Achievements Section** - Academic and extracurricular accomplishments
- **Languages Section** - Language proficiency
- **Contact Section** - Easy way to get in touch
- **Modern UI Design** - Clean, professional, and visually appealing
- **Mobile-Friendly Layout** - Seamless experience across all screen sizes
- **Smooth Animations** - Engaging hover effects and transitions
- **Interactive Elements** - Modal for viewing images, smooth scrolling

🛠 Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Styling, animations, and responsive design
- **JavaScript** - Interactive functionality and DOM manipulation
- **Responsive Web Design** - Mobile-first approach with media queries
- **FontAwesome** - Icons for visual enhancement
